\# Titanic Survival Prediction 🚢



\## Overview

This project is my machine learning solution to the Kaggle Titanic - Machine Learning from Disaster competition.



The goal is to predict whether a passenger survived the Titanic disaster based on passenger information such as age, gender, ticket class, family size, and other features.



This is one of my first end-to-end machine learning projects, covering data analysis, feature engineering, model training, evaluation, and Kaggle submission.



\## Kaggle Score

\- \*\*Public Leaderboard Score:\*\* 0.73684

\- \*\*Best Model:\*\* Random Forest Classifier

\- \*\*Cross-Validation Accuracy:\*\* 83.01%



\## Methods Used

\- Exploratory Data Analysis (EDA)

\- Missing Value Handling

\- Feature Engineering

\- Logistic Regression

\- Random Forest Classifier

\- GridSearchCV

\- 5-Fold Cross-Validation



\### Feature Engineering

Some engineered features include:

\- FamilySize

\- IsAlone

\- Title

\- Deck
